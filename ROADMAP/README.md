# ROADMAP

Percorso ufficiale di sviluppo e stato di avanzamento del progetto Mandari.

- [Architettura di Percorso](Architettura_di_Percorso.md) — fasi, regole e stato corrente.

La ROADMAP è l'unico riferimento ufficiale dello stato del progetto.
