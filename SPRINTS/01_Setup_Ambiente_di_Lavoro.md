# SPR-001

# Setup Ambiente di Sviluppo

Versione: 1.0

Stato: Review

---

# 1. Obiettivo

Preparare l'ambiente di sviluppo completo di Mandari.

Al termine dello Sprint dovrà essere possibile avviare localmente il progetto completo senza errori.

---

# 2. Risultato Atteso

Il repository dovrà contenere la struttura definitiva del progetto.

Frontend e Backend dovranno avviarsi correttamente.

Il Database dovrà essere collegato.

Il progetto dovrà essere pronto per iniziare lo sviluppo delle funzionalità.

---

# 3. Attività

## Repository

- verifica della struttura GitHub
- verifica delle cartelle progetto

---

## Frontend

- creazione progetto Next.js
- configurazione TypeScript
- configurazione Tailwind CSS
- verifica avvio locale

---

## Backend

- creazione progetto Python
- installazione FastAPI
- installazione Uvicorn
- verifica avvio locale

---

## Database

- creazione progetto Supabase
- collegamento Backend
- verifica connessione PostgreSQL

---

## Versionamento

- primo commit stabile

---

# 4. Deliverable

Al termine dello Sprint dovranno esistere:

Frontend funzionante

Backend funzionante

Database collegato

Repository aggiornato

Documentazione aggiornata

---

# 5. Criterio di Completamento

Lo Sprint viene considerato completato quando:

✓ Frontend avviato.

✓ Backend avviato.

✓ Database raggiungibile.

✓ Repository aggiornato.

✓ Nessun errore bloccante presente.
